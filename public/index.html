pdf-encrypt

替 PDF 蓋上一枚加密印章。加密、解密、檢視權限與文件屬性，一個命令列工具全包。

安裝 pdf-encrypt
常見問題權限、隱私、忘記密碼、原檔與平台 演算法與權限四種演算法、八種權限、三種密碼組合 功能加密、權限、重新加密、文件屬性 指令產生器勾選選項，產生 bash 或 PowerShell 指令

一行裝好

單一執行檔，不需要 Rust、Python 或任何 PDF 函式庫。支援 macOS、Linux、Windows 的 x64 與 ARM64。

組合加密指令 
curl -fsSL https://raw.githubusercontent.com/doggy8088/pdf-encrypt/main/install.sh | sh

下載對應平台的執行檔、驗證 SHA-256，再安裝到 ~/.local/bin。指定版本與目錄：| sh -s -- --version 0.3.1 --to ~/bin。

irm https://raw.githubusercontent.com/doggy8088/pdf-encrypt/main/install.ps1 | iex

在 PowerShell 執行。安裝到 %LOCALAPPDATA%\Programs\pdf-encrypt\bin，並把該目錄加入使用者 PATH。

npm install -g @willh/pdf-encrypt

需要 Node.js 18 以上。npm 只下載符合目前平台的執行檔，不執行 postinstall。不安裝直接試用：npx @willh/pdf-encrypt --help。

cargo install pdf-encrypt --locked

已安裝 Rust 工具鏈時，從 crates.io 編譯安裝。

  • Windows x64 安裝程式 (.msi)
  • macOS Apple 晶片 (.pkg)
  • macOS Intel (.pkg)
  • Debian、Fedora 套件與壓縮檔 (.deb、.rpm)

三步蓋好印章

  1. 幾秒鐘 先用一行指令裝好單一執行檔。
  2. 約一分鐘 接著選好密碼、權限與演算法，組出指令。
  3. 不到一秒 最後執行，寫出加密後的 PDF。

實測：61 頁、3.5 MB 的 PDF 以 AES-256 加密耗時 0.52 秒；安裝指令稿在一般網路下約 4 秒完成。

    一個工具，六件事

    每一件都能單獨使用，也能在同一個指令裡一起完成。

    • 預設 AES-256

      PDF 2.0 標準安全處理器；需要相容舊版 reader 時可改用 AES-128 或 RC4。

    • 八種檢視權限

      列印、複製、修改、註解、填表、組合頁面等逐項允許或禁止，或用 --read-only 一次設為唯讀。

    • 重新加密

      以舊密碼開啟已加密的 PDF，直接換成新密碼或新演算法。

    • 讀寫文件屬性

      info --json 讀取 Document Info 與 XMP；edit 只改指定欄位，保留既有加密。

    • 單一執行檔

      以 Rust 與 lopdf 直接讀寫 PDF，不呼叫 qpdf、Ghostscript 或 pdftk。

    • 適合 AI 代理與 CI

      JSON 輸出、明確的結束碼與 --force 非互動模式，並附 Agent Skill。

    演算法與權限

    演算法

    • aes-256 預設，新文件建議使用PDF 2.0
    • aes-128 相容較舊的 PDF readerPDF 1.5
    • rc4-128 舊系統相容用途PDF 1.4
    • rc4-40 僅供極舊系統，不建議PDF 1.4

    檢視權限

    • 列印文件print
    • 高品質列印high-quality-print
    • 修改內容modify
    • 複製或擷取內容copy
    • 新增或修改註解annotate
    • 填寫表單fill-forms
    • 輔助使用的內容擷取accessibility
    • 組合頁面或大綱assemble

    密碼組合

    • 只設開啟密碼：擁有者密碼自動相同，知道密碼的人有完整權限機密
    • 只設擁有者密碼：任何人都能開啟，但 reader 套用權限限制唯讀發布
    • 兩者都設：開啟密碼受限，擁有者密碼享完整權限分級
